# بازبینی نیازمندی‌ها و وضعیت واقعی

این جدول بر مبنای فایل‌ها و آزمون‌های موجود است، نه وعده تکمیل محصول. «جزئی» به معنی آماده بودن قابلیت برای بهره‌برداری نیست.

| حوزه | وضعیت | کارهای مهم باقی‌مانده |
|---|---|---|
| معماری، Firebase و Room | جزئی | راه‌اندازی پروژه واقعی، schema کامل و migration، امنیت و بکاپ، integration چنددستگاهی |
| حالت معرفی و برند | موجود برای نمایش | چهار تم، دسترس‌پذیری و تطبیق رابط‌های عملیاتی |
| هویت و نقش‌ها | جزئی | ایجاد و مدیریت کامل حساب‌ها و دستگاه مجاز، بازیابی امن نشست، آزمون فوری لغو دسترسی؛ راه‌اندازی مدیر اولیه نیازمند هویت Google مجاز است |
| خودرو و راننده | جزئی: ثبت و فهرست مدیر | ویرایش، یکتایی پلاک، راننده جایگزین، تاریخچه کامل، بیمه و معاینه؛ انتساب اولیه مدیر و خاتمه با audit اضافه شده، ماژول یخچال طبق درخواست حذف شده است |
| درخواست سوخت و سهمیه | جزئی: فرمان سرور، صف محلی، رابط اولیه راننده و حسابدار | تنظیمات و انتساب درون برنامه، تاریخچه سیاست، همگام‌سازی انتهابه‌انتها روی دستگاه واقعی، اصلاح مالی، رسید و بررسی هم‌زمانی روی دستگاه |
| GPS گوشی و مسافت | جزئی: هسته محاسبه و فیلتر | Foreground Service، مجوزهای نسخه‌های جدید، توقف، ذخیره و ارسال دسته‌ای، نقشه، آزمون میدانی و مصرف باتری |
| موجودی باک و هشدار مسیر برگشت | ساخته نشده | تخمین، درجه اطمینان، آستانه‌ها و داده واقعی مسیر |
| جایگاه هوشمند | ساخته نشده | منبع معتبر جایگاه، تشخیص توقف/حرکت، اعلان و تأیید یا رد راننده |
| مشتری، مأموریت و تحویل | ساخته نشده | چند مقصد، ترتیب، امضا، رسید، مغایرت و گزارش مأموریت |
| سرویس و تعمیرات خودرو | جزئی در نسخه آزمایشی محلی | موعد شمسی/مسافت، رسید و هزینه واقعی و اعلان؛ مدیریت سیستم یخچال طبق درخواست اخیر حذف شد |
| نقشه و دستیار | ساخته نشده | انتخاب سرویس معتبر ایران، ترافیک، مسیر جایگزین، نقاط خطر معتبر، صدای فارسی و محدودیت اعلان |
| حسابداری و گزارش | ساخته نشده | گزارش‌های داده واقعی، PDF، Excel، چاپ، مجوزها و اصلاح جبرانی |
| امنیت و انتشار | جزئی | ارزیابی امنیت، تست قوانین و دستگاه، ثبت audit جامع، بازیابی، امضای release و انتشار |

اولویت بعدی: مدیریت امن حساب‌ها و تنظیمات، رفع خطاها و آزمون end-to-end چنددستگاهی پیش از استفاده از سوخت واقعی. GPS و بقیه ماژول‌ها همچنان لازم‌اند و حذف نشده‌اند.

بازبینی اخیر: ایجاد خودروی واقعی با تابع مدیر، قفل اتمی پلاک و امکان تکرار درخواست همسان انجام می‌شود؛ برای داده‌های قبلی مهاجرت اجباری طبق راهنمای Firebase لازم است. محدودیت حجم سوخت به ظرفیت مخزن در سرور اعمال می‌شود؛ خودروهای بدون ظرفیت معتبر ابتدا باید اصلاح شوند. پاسخ نامشخص ثبت خودرو باید با بررسی فهرست و ارسال مجدد همان فرم پیگیری شود؛ شناسه تکرار فرم فقط در حافظه برنامه حفظ می‌شود، نه پس از پایان فرایند. این موارد جایگزین تست عملیاتی و تکمیل بخش‌های باقی‌مانده نیستند.
